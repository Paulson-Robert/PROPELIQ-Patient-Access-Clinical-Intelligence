# User Story - US_001

## Story ID

- ID Format: US_001

## Story Title

- Frontend Project Scaffold with React and Vite

## Description

- As a **developer**, I want a fully configured React 18+ / Vite frontend project scaffold with TailwindCSS and Shadcn UI integrated, so that all feature epic frontend development can begin on a consistent, standards-compliant foundation.

## Acceptance Criteria

### AC-01: Vite project initializes and builds successfully

- **Given**: A clean development environment with Node.js 20+ and pnpm installed
- **When**: The developer runs `pnpm install` followed by `pnpm build` in the frontend project directory
- **Then**: The project installs all dependencies without errors and produces a production build in the `dist/` directory with zero build warnings

### AC-02: Development server starts and renders root route

- **Given**: The frontend project dependencies are installed
- **When**: The developer runs `pnpm dev`
- **Then**: The Vite development server starts on the configured port (default 5173) and the root route (`/`) renders a placeholder page within 3 seconds of server start

### AC-03: TailwindCSS utility classes are functional

- **Given**: The development server is running
- **When**: A developer adds a TailwindCSS utility class (e.g., `bg-primary text-white p-4`) to a React component
- **Then**: The utility class is applied correctly in the browser with hot module replacement reflecting changes within 500ms

### AC-04: Shadcn UI components render correctly

- **Given**: Shadcn UI is initialized with the project's design token configuration
- **When**: A developer imports and renders a Shadcn UI `Button` component
- **Then**: The button renders with the configured design tokens (color, radius, font) and is interactive (hover, focus, click states functional)

### AC-05: Project uses only free and open-source dependencies

- **Given**: The frontend project scaffold is complete
- **When**: The dependency tree is audited via `pnpm licenses list`
- **Then**: All dependencies use OSI-approved open-source licenses (MIT, Apache 2.0, ISC, BSD) with zero proprietary or paid dependencies

## Edge Cases

- **Node.js version mismatch**: If a developer uses Node.js < 20, the project should fail with a clear `.nvmrc` or `engines` field error indicating the minimum version requirement
- **pnpm lock conflict**: If `pnpm-lock.yaml` is corrupted or stale, `pnpm install` should regenerate it without manual intervention
- **Port conflict**: If port 5173 is occupied, Vite should auto-increment to the next available port and log the actual port number
