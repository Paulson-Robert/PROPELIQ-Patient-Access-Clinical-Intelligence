# User Story - US_040

## Story ID

- ID Format: US_040

## Story Title

- ICD-10 and CPT Code Mapping

## Description

- As a **staff member**, I want the system to suggest ICD-10-CM and CPT-4 codes based on aggregated patient data with confidence indicators and source references, so that I can verify and finalize medical codes for billing and clinical documentation.

## Acceptance Criteria

### AC-01: ICD-10 codes are suggested from patient diagnoses

- **Given**: A patient's 360-Degree Patient View contains aggregated diagnoses
- **When**: The staff member opens the code mapping view (SCR-021)
- **Then**: The system presents suggested ICD-10-CM codes mapped from diagnosis data, each with a confidence score, code value, description, and source data reference

### AC-02: CPT codes are suggested from patient procedures

- **Given**: A patient's 360-Degree Patient View contains aggregated procedures
- **When**: The staff member opens the code mapping view (SCR-021)
- **Then**: The system presents suggested CPT-4 codes mapped from procedure data, each with a confidence score, code value, description, and source data reference

### AC-03: Confidence indicators distinguish suggestion quality

- **Given**: Suggested codes are displayed
- **When**: The staff member reviews the code list
- **Then**: High-confidence codes (≥0.85) are marked with a green indicator, medium-confidence codes (0.60–0.84) with amber, and low-confidence codes (<0.60) with red "Manual Review Required" flag

### AC-04: Staff verifies, modifies, or rejects each code

- **Given**: The code mapping view displays suggested codes
- **When**: The staff member reviews a suggested code
- **Then**: The staff member can accept (verify), modify (edit code or description), or reject the code, and each action is recorded in MedicalCodeMapping with the appropriate source tag

### AC-05: Staff can manually add codes not suggested by AI

- **Given**: The AI did not suggest a relevant code
- **When**: The staff member clicks "Add Code" and searches the ICD-10-CM or CPT-4 reference tables
- **Then**: The manually added code is stored in MedicalCodeMapping with "Staff Override" source tag and the appropriate CodeSetVersion

### AC-06: Code verification contributes to AI-Human Agreement Rate

- **Given**: The staff member verifies or rejects AI-suggested codes
- **When**: The verification is saved
- **Then**: The accept/modify/reject outcome is recorded for the model accuracy monitoring system (US_037) and contributes to the ongoing Agreement Rate calculation

## Edge Cases

- **No matching codes found**: If the AI/rule-based engine cannot map any codes from the patient data, the system displays "No codes suggested — please add codes manually" with the manual add option
- **Outdated code set version**: If the patient's extraction was performed with an older code set version and a newer version is now available, the system should display a warning "Code set has been updated — consider re-mapping"
- **Duplicate code suggestions**: If the same code is suggested from multiple data sources, it should appear once with references to all contributing sources
