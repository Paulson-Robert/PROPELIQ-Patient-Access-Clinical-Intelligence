# User Story - US_050

## Story ID

- ID Format: US_050

## Story Title

- Shared Layout Shell and Navigation

## Description

- As a **platform user**, I want a consistent navigation layout with a header, sidebar (desktop), bottom navigation bar (mobile), and role-based menu items, enabling any primary task to be completed within 3 clicks from the dashboard.

## Acceptance Criteria

### AC-01: Layout shell renders with header and sidebar on desktop

- **Given**: A user is logged in on a desktop viewport (≥1024px)
- **When**: Any authenticated page loads
- **Then**: The layout includes a fixed header with logo, user avatar, and logout action, and a sidebar navigation panel with role-appropriate menu items

### AC-02: Role-based menu items are displayed

- **Given**: A user with a specific role (Patient, Staff, Admin) is logged in
- **When**: The navigation renders
- **Then**: Only menu items authorized for that role are displayed — patients see booking/intake/documents, staff see queue/schedule/patient views, admins see user management/audit/metrics

### AC-03: Three-click navigation rule is satisfied

- **Given**: A user is on their role-specific dashboard
- **When**: The user needs to perform any primary task (book appointment, view queue, manage users, etc.)
- **Then**: The task is reachable within 3 clicks from the dashboard (UXR-101)

### AC-04: Active navigation state is highlighted

- **Given**: A user navigates to a specific page
- **When**: The page is active
- **Then**: The corresponding navigation item is visually highlighted with an active state indicator (background color, left border, or icon weight change)

### AC-05: Mobile bottom navigation replaces sidebar

- **Given**: A user is on a mobile viewport (<768px)
- **When**: The layout renders
- **Then**: The sidebar is hidden and replaced by a bottom navigation bar with the most important role-based actions (max 5 items)

### AC-06: Navigation collapse/expand on tablet

- **Given**: A user is on a tablet viewport (768px–1023px)
- **When**: The layout renders
- **Then**: The sidebar is collapsed to icon-only mode with a toggle button to expand to full labels

## Edge Cases

- **Rapid route changes**: If the user navigates between pages quickly, the active state should update synchronously with the route change without flickering
- **Deep link with expired session**: If a user follows a deep link to a specific page and their session is expired, the login redirect should preserve the original URL for post-login navigation
- **Menu overflow on mobile**: If the role has more than 5 primary navigation items, the mobile bottom bar should show the top 5 with a "More" overflow menu
