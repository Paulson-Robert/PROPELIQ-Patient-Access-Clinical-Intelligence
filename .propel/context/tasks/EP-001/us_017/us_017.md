# User Story - US_017

## Story ID

- ID Format: US_017

## Story Title

- Session Timeout Warning and Expiry Redirect

## Description

- As a **platform user**, I want to see a warning dialog 2 minutes before my session expires with the option to extend it, and be gracefully redirected to the login page when the session does expire, so that I do not lose unsaved work unexpectedly.

## Acceptance Criteria

### AC-01: Timeout warning dialog appears at 2-minute mark

- **Given**: A user has an active session with 2 minutes remaining before the 15-minute sliding expiry
- **When**: The 2-minute threshold is reached without user activity
- **Then**: A modal dialog (MOD-001) appears with the message "Your session will expire in 2 minutes" with a countdown timer, "Extend Session" button, and "Log Out" button

### AC-02: Extend session resets the sliding expiry

- **Given**: The session timeout warning dialog is displayed
- **When**: The user clicks "Extend Session"
- **Then**: The dialog closes, the session expiry is extended by 15 minutes, and the user continues working without interruption

### AC-03: Session expiry redirects to login with message

- **Given**: The session timeout warning dialog is displayed (or the session expires without the dialog being acted upon)
- **When**: The session token expires
- **Then**: The user is redirected to the login page (SCR-001) with a toast message "Your session has expired. Please log in again." and the return URL is preserved for post-login redirect

### AC-04: Post-login redirect returns user to previous page

- **Given**: A user's session expired while on a specific page (e.g., appointment booking)
- **When**: The user logs in again
- **Then**: The user is redirected back to the page they were on before the session expired

### AC-05: Log Out button from warning dialog ends session cleanly

- **Given**: The session timeout warning dialog is displayed
- **When**: The user clicks "Log Out"
- **Then**: The session is terminated, Redis session data is cleared, and the user is redirected to the login page without the "session expired" toast

## Edge Cases

- **Multiple browser tabs**: The timeout warning should appear in all active tabs for the same session; extending in one tab should dismiss the dialog in others
- **Background tab**: If the browser tab is in the background when the warning triggers, the dialog should appear when the user returns to the tab
- **Network disconnection during extend**: If the session extension request fails due to network issues, the dialog should display a "Failed to extend — please save your work and log in again" message
