# User Story - US_020

## Story ID

- ID Format: US_020

## Story Title

- Appointment Cancellation and Rescheduling

## Description

- As a **patient**, I want to cancel or reschedule my upcoming appointments, so that I can manage my schedule and released slots become available to other patients or trigger preferred slot swaps.

## Acceptance Criteria

### AC-01: Patient cancels an appointment with confirmation

- **Given**: The patient has an upcoming appointment with "Scheduled" status on the appointment detail page (SCR-007)
- **When**: The patient clicks "Cancel Appointment" and confirms via the cancellation dialog (MOD-003)
- **Then**: The appointment status is updated to "Cancelled", the time slot is released back to availability, and a cancellation confirmation email is sent to the patient

### AC-02: Cancellation triggers preferred slot swap check

- **Given**: Other patients have preferred slot preferences for the now-released slot
- **When**: The slot is released via cancellation
- **Then**: The system triggers the preferred slot swap engine (US_019) to evaluate waiting queue entries for the released slot

### AC-03: Patient reschedules to a new available slot

- **Given**: The patient is on the appointment detail page (SCR-007) with a "Scheduled" appointment
- **When**: The patient clicks "Reschedule", selects a new time slot from available options (SCR-008), and confirms
- **Then**: The system acquires a lock on the new slot, moves the appointment to the new slot with a slot lock countdown, releases the original slot, and sends a rescheduling confirmation email with updated details

### AC-04: Reschedule slot conflict refreshes available slots

- **Given**: The patient selects a new slot during rescheduling
- **When**: The selected slot is taken by another user before the lock is acquired
- **Then**: The system displays "This slot is no longer available" and refreshes the available slot list

### AC-05: Calendar sync updates after cancellation or reschedule

- **Given**: The patient has calendar sync configured
- **When**: An appointment is cancelled or rescheduled
- **Then**: The external calendar event is deleted (cancellation) or updated (reschedule) via an async background job

### AC-06: Cancel the cancellation returns to dashboard

- **Given**: The cancellation confirmation dialog (MOD-003) is displayed
- **When**: The patient clicks "Keep Appointment" or closes the dialog
- **Then**: No changes are made and the patient returns to the appointment detail page

## Edge Cases

- **Reschedule to same slot**: The system should prevent rescheduling to the same time slot currently held, displaying "You already have this slot" guidance
- **Past appointment**: Cancel and reschedule options should not be available for appointments with "Completed", "Cancelled", or "No-Show" status
- **Rapid cancellation clicks**: Multiple rapid clicks on "Cancel" should not create duplicate cancellation operations; the button should be disabled after the first click
