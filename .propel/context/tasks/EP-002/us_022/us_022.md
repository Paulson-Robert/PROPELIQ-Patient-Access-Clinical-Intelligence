# User Story - US_022

## Story ID

- ID Format: US_022

## Story Title

- Appointment History View

## Description

- As a **patient**, I want to view my complete appointment history showing past and upcoming appointments with status indicators, so that I can track my healthcare schedule in one place.

## Acceptance Criteria

### AC-01: Appointment history displays all patient appointments

- **Given**: The patient is logged in and navigates to the appointment history page (SCR-016)
- **When**: The page loads
- **Then**: The system displays all the patient's appointments (past and upcoming) sorted by date (newest first) with columns for date, time, provider, specialty, and status

### AC-02: Status indicators distinguish appointment states

- **Given**: The appointment history page is displayed
- **When**: Appointments with different statuses exist (Scheduled, Arrived, Completed, Cancelled, No-Show)
- **Then**: Each status is displayed with a distinct color-coded badge and icon per the design system (e.g., green for Completed, amber for Scheduled, red for Cancelled/No-Show)

### AC-03: Upcoming appointments show action buttons

- **Given**: The appointment history contains upcoming appointments with "Scheduled" status
- **When**: The patient views an upcoming appointment
- **Then**: "View Details", "Reschedule", and "Cancel" action buttons are displayed for that appointment

### AC-04: Past appointments show view-only details

- **Given**: The appointment history contains past appointments with "Completed" or "No-Show" status
- **When**: The patient views a past appointment
- **Then**: Only a "View Details" button is displayed; no cancel or reschedule actions are available

### AC-05: Empty state for new patients

- **Given**: A patient has no appointment history
- **When**: The patient navigates to the appointment history page
- **Then**: The system displays a zero-state message "No appointments yet" with a "Book Your First Appointment" call-to-action linking to the appointment search page (SCR-005)

## Edge Cases

- **Large appointment history**: For patients with 100+ appointments, the list should be paginated (20 per page) with a "Load more" button or pagination controls
- **Appointment status change while viewing**: If an appointment status changes while the patient is on the history page (e.g., swap occurs), the page should update on next navigation or manual refresh
- **Timezone display**: Appointment times should be displayed in the patient's local timezone based on browser settings
